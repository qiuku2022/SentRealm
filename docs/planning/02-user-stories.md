# 用户故事

> **权威范围**仍以 [产品定义与 MVP](./01-product-definition-and-mvp.md) 为准。本文从**使用者视角**列出需求场景，供验收与排期对照；操作步骤见 [用户手册](../user/README.md)。

**读者**：产品、开发、验收  
**角色**：

| 角色 | 说明 |
|------|------|
| 写稿人 | 撰写并定稿口播/解说/采访类文稿 |
| 统筹 | 在写稿与剪辑之间流转预处理稿 |
| 剪辑 | 在剪映中做「文稿匹配」生成字幕（间接受益） |
| 开发者 / Agent | 用 cli 或 MCP 批处理、联调（非终端主角色） |

故事格式：`作为…，我想要…，以便…`；验收用可观察结果描述。

---

## 1. 主流程（MVP 必达）

### US-01 粘贴并处理定稿

**作为**写稿人，**我想要**把定稿全文粘贴进 SentRealm 并一键处理，**以便**得到适合剪映文稿匹配的分行文本。

**验收**

- 粘贴非空文稿后可触发处理
- 结果为无空行、一行一条字幕的纯文本
- 默认去标点（保留 `%` / `.`）并在去除位置换行

### US-02 导入 .txt

**作为**写稿人，**我想要**导入 UTF-8 的 `.txt` 文件，**以便**不必手工全选粘贴长稿。

**验收**

- 可选文件导入；导入后可与粘贴稿同样处理
- 非法/空文件有明确失败提示（不静默成功）

### US-03 横屏 / 竖屏预设

**作为**写稿人，**我想要**一键选择横屏（15 字）或竖屏（10 字），**以便**匹配成片画幅而不必记数字。

**验收**

- 选横屏后单行上限为 15；竖屏为 10
- 切换预设后再次处理结果符合新上限（或标记仍超限行）

### US-04 自定义字数

**作为**写稿人，**我想要**自定义单行最大字数，**以便**适配特殊字幕宽度。

**验收**

- 可设 ≥1 的整数；非法值被拒绝
- 处理严格执行该上限

### US-05 对照预览与行数

**作为**写稿人，**我想要**看到原文与处理后对照、行数统计，**以便**复制前确认质量。

**验收**

- 可查看处理后文本与行数
- 超长标记行有醒目标识（见 US-08）

### US-06 一键复制

**作为**写稿人，**我想要**一键复制处理结果，**以便**粘贴到剪映或发给剪辑。

**验收**

- 剪贴板内容为处理后全文（非原文）
- 无多余空行

### US-07 交给剪辑 / 剪映匹配

**作为**统筹或写稿人，**我想要**把预处理稿交给剪辑在剪映中文稿匹配，**以便**减少字幕轨返工。

**验收**

- 交付物仅为可复制文本（不要求自动写入剪映工程）
- 抽样粘贴后，绝大多数条目无需再去标点或大幅改长度（允许少量微调）

## 2. 断句与质量

### US-08 超长行标记

**作为**写稿人，**我想要**看到规则（及可选 LLM）后仍超长的行被标记，**以便**手工改短或接受风险后再复制。

**验收**

- 标记行内容仍输出；UI 高亮或等价提示
- 未配置 / 未启用 LLM 时，规则切不掉的行进入标记（不崩溃）

### US-09 无 LLM 也能用

**作为**写稿人，**我想要**在不配置 LLM 密钥时仍能完成去标点与规则断句，**以便**离线或无 API 预算时工作。

**验收**

- `llm_enabled=false` 或缺 endpoint/model/密钥时跳过 LLM 步骤
- 核心去标点、空格规范化、规则断句仍可用

### US-10 可选 LLM 语义断句

**作为**写稿人，**我想要**对规则后仍超长的行做语义切分且不改写用词，**以便**减少标记行。

**验收**

- 仅当启用条件满足时调用（见 ADR-005）
- 规则后仍超长的行进入发送池；每批最多 10 行；结果写回原位
- 质检：每行字数 ∈ `[min_chars, max_chars]`（`min_chars` 来自设置，默认 5），且拼接后与原文句意守恒；不合格回池，每行最多 3 次后标记
- 不上传全文；不润色、不纠错
- 失败 / 放弃时降级为标记，不阻断整次处理

### US-11 自定义去标点规则

**作为**写稿人，**我想要**调整「去除并换行」与「保留」符号集，**以便**适配稿件中的特殊符号（如保留 `+`）。

**验收**

- 可改保留/去除列表并持久化到本机配置
- 下次启动仍生效；三入口（gui/cli/mcp）共用同一配置库

## 3. 工作区与恢复（gui）

### US-12 项目与文稿切换

**作为**写稿人，**我想要**在多个项目/文稿间切换，**以便**并行推进不同成片的口播稿。

**验收**

- 可新建、重命名、删除项目/文稿（删除冲突时有明确错误，如最后一个项目）
- 可切换活动文稿；内容来自本机工作区目录

### US-13 重启后恢复

**作为**写稿人，**我想要**关闭应用后再次打开仍能看到上次文稿，**以便**不必反复粘贴。

**验收**

- 正文落在 `Documents/SentRealm/`（或平台等价路径）
- 冷启动可恢复活动项；损坏指针可修复或回退

### US-14 缓存最近处理结果

**作为**写稿人，**我想要**保留最近一次处理结果，**以便**回看而不必立刻重跑。

**验收**

- 可通过 API/UI 写入最近 `result.json`
- `POST /preprocess` 本身不自动写盘（与 ADR-010 一致）

## 4. 异常与边界

### US-15 空文稿

**作为**写稿人，**我想要**在文稿为空时得到明确错误，**以便**知道需要粘贴内容。

**验收**：空或仅空白 → 处理失败提示（如 HTTP 400），不产生假成功结果。

### US-16 后端未就绪

**作为**写稿人，**我想要**在后端未启动或端口占用时看到可读提示，**以便**知道如何处理而非白屏。

**验收**：显示「后端未就绪」或等价文案；端口 17300 冲突时可依据文档排查。

### US-17 英文、百分号与小数点

**作为**写稿人，**我想要**英文词、`%` 与小数点按产品规则保留，**以便**口播中的品牌名、增长率、小数与版本号不被拆坏。

**验收**：符合产品定义空格规则与默认保留 `%`/`.`；规则断句不切断英文单词。

---

## 5. 多入口（非 GUI 主路径）

### US-18 CLI 预处理

**作为**开发者，**我想要**用 `sentrealm preprocess` 从文件或 stdin 处理，**以便**脚本化。

**验收**：stdout 为 processed；stderr 为 JSON 元数据；退出码符合 [cli-mcp.md](../cli-mcp.md)。

### US-19 MCP 预处理

**作为**在 Cursor 中写稿的用户，**我想要**通过 `preprocess_text` tool 处理文稿，**以便**在 Agent 流程中复用同一流水线。

**验收**：返回结构与 HTTP `PreprocessResponse` 一致；与 gui 在相同 Settings 下结果一致。

---

## 6. 非目标（明确不做）

下列**不是**用户故事，避免验收时误当缺口：

| 不做 | 说明 |
|------|------|
| 自动写入剪映工程 | 无开放接口；交付物为文本 |
| SRT/ASS 导出、时间轴对齐 | 后续可扩展 |
| 改写 / 润色 / 纠错 | 仅格式与断句 |
| ASR 实时转写 | 非本产品场景 |
| 云端同步、多用户权限 | 本地工具 |
| GUI 批量多文件 | MVP 单篇；CLI 可自行循环 |
