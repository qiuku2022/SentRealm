# SentRealm 用户使用手册

面向**写稿人、统筹与剪辑协作**的使用说明：如何把定稿口播/解说稿处理成适合剪映「文稿匹配」的文本。

| 项 | 说明 |
|----|------|
| 产品定位 | 见 [产品定义与 MVP](../planning/01-product-definition-and-mvp.md) |
| 当前版本阶段 | Phase 1 MVP 核心（见 [CHANGELOG](../../CHANGELOG.md) `0.2.0`） |
| 分发状态 | **正式公开发布尚未完成**（路线图 M3）。团队可用 [packaging.md](../dev/packaging.md) 打出内部 NSIS 安装包；终端用户也可由团队提供该构建 |
| 主平台 | Windows 10 / 11 |

开发者请改读 [开发指南](../dev/README.md)，不要用本文当环境搭建手册。

---

## 1. 它解决什么问题

剪映「文稿匹配」若直接粘贴带标点、过长的原稿，常见问题是：

- 字幕里残留逗号、句号等符号
- 单条字幕太长，需要在剪映里逐条改

SentRealm 在**粘贴进剪映之前**完成本地预处理：去标点、识别自然停顿、规范空格并按字数智能断句。你拿到的是「一行一条字幕」的纯文本，再复制到剪映即可。

**它不会**：改写文案、对接剪映工程、导出 SRT、做语音转写。交付物是**可复制的纯文本**（也可导出为 `.txt`）。

---

## 2. 你需要准备什么

| 准备 | 说明 |
|------|------|
| 定稿文稿 | 口播/解说/采访类**已确认**的文字；非实时转写为主场景 |
| 剪映 | 本机已安装；使用「文本 → 智能字幕 → 文稿匹配」（菜单以你的剪映版本为准） |
| SentRealm | 安装包就绪前：按团队说明启动桌面应用；开发者可用 `pnpm dev`（见开发文档） |
| （可选）LLM | 仅当希望「规则断不干净的超长行」再语义切分时需要；**不配置也能用**核心去标点与规则断句 |

## 3. 主流程（写稿 → 剪映）

推荐一次只处理**一篇**定稿。

### 步骤 A — 打开 SentRealm

1. 启动应用，等待窗口就绪。  
2. 若界面提示「后端未就绪」或「后端已停止」，见 [§7 常见问题](#7-常见问题)。  
3. 主界面为**三栏**：左侧项目/文稿（默认工作区）、中间编辑与参数、右侧「处理结果」预览。
4. **快捷键**：`Ctrl+,` 打开/关闭设置；在编辑区外按 `/` 可聚焦左侧「搜索文稿…」。

### 步骤 A2 — 侧栏与工作区

文稿与项目**默认**保存在本机工作区（见 [§5](#5-数据存在哪里本机)），关闭应用后仍在。

- **搜索**：在左栏输入标题关键词，或按 `/` 聚焦搜索框。  
- **折叠**：点击品牌行旁的折叠钮，可收拢侧栏以腾出编辑空间。  
- **重命名 / 删除**：文稿行右侧 `⋯` 菜单；删除前会二次确认。**不能删除当前正在编辑的文稿**——请先切换到其他文稿或新建一篇。  
- **窄窗口**：宽度较小时，右侧「处理结果」改为抽屉；中栏头会出现 **结果** 按钮打开预览。

### 步骤 B — 输入文稿

任选其一：

- **粘贴**：把定稿全文粘贴到文稿编辑区  
- **导入**：导入 `.txt` 文件（UTF-8 推荐）

建议先确认文稿与成片口播一致，再处理；SentRealm **不会**根据视频改字。

### 步骤 C — 选择参数

| 参数 | 怎么选 |
|------|--------|
| **横屏** | 单行最多约 **15** 字，适合横屏成片字幕宽度 |
| **竖屏** | 单行最多约 **10** 字，适合竖屏/短视频 |
| **自定义** | 自行指定单行最大字数（正整数） |
| **最小字数** | 自动规则切分后每行不少于该字数（默认 5；原文本身完整的短句不受此限）；LLM 语义切分不受此限 |

多数团队先用横屏或竖屏预设；只有字幕偏宽/偏窄再改自定义。最小字数可按口播节奏调高或调低，但不能大于当前最大字数。

去标点与 LLM 等进阶项见 [§4](#4-参数与规则说明)。

### 步骤 D — 一键处理

底部浮动栏（FAB）从左到右大致为：**设置**、**预设**、状态文案、**编辑规则**、**处理文稿**。

- **编辑规则**（可选）：打开断句词表窗口，按口播习惯增删「可在何处断行」的字词；保存后下次处理生效。详见 [§4.5](#45-编辑断句词表可选进阶)。
- 若已在设置中**启用 LLM 断句**，点击「处理文稿」前会先做**连通性预检**；失败会弹窗提示，不会开始处理。
- 点击 **处理文稿**（处理完成后按钮变为 **重新处理**）。处理过程中，右侧「处理结果」会**随进度刷新**；完成后可复制或导出。

你会看到：

| 信息 | 含义 |
|------|------|
| 处理后文本 | 每行一条字幕，**无空行**；结果栏带行号与每行字数 |
| 行数 / 统计 | 大约对应剪映里字幕条数；分栏统计含超限行数等 |
| **高亮 / 标记行** | 规则（以及可选的 LLM）之后**仍超过字数上限**的行——需要你人工改短或接受略超长 |

未配置 LLM 时：超长行在规则断句后若仍超限，会直接进入标记，这是预期行为，不是故障。

### 步骤 E — 检查标记行

复制前请扫一眼高亮行：

1. 能否在句意完整处手动拆成两行？  
2. 是否有专有名词、英文品牌名被拆得不理想？  
3. 百分号 `%` / `％` 是否仍在（默认应保留，如 `增长50%`）？

不必追求「零标记」；产品成功标准允许剪映内少量微调。

### 步骤 F — 复制或导出结果

任选其一：

- **一键复制**：复制按钮把处理后全文写入剪贴板，再粘贴到剪映。  
- **导出 .txt**：结果栏下载图标 → 对话框中选「导出到文稿目录」（写入当前文稿文件夹，文件名取自文稿标题），或「选择其他位置…」另存。

文稿目录位于工作区 `Documents\SentRealm\projects\…\documents\…\`，与 `source.txt` 同级。

### 步骤 G — 粘贴到剪映

1. 打开剪映工程与对应视频轨。  
2. 进入 **文本 → 智能字幕 → 文稿匹配**（路径因版本可能略有差异）。  
3. 粘贴 SentRealm 的结果文本。  
4. 执行匹配，生成字幕轨。  
5. 抽查几条：标点是否已无、长度是否可接受；对标记过的难句重点听片核对。

### 步骤 H — 交给剪辑（协作时）

写稿方可将处理后的 `.txt` 或直接粘贴内容发给剪辑，并注明：

- 使用的预设（横屏 15 / 竖屏 10 / 自定义 N）  
- 是否仍有未改的标记行  
- 对应成片/口播版本号（避免稿片不一致）

## 4. 参数与规则说明

更细的产品规则见 [产品定义](../planning/01-product-definition-and-mvp.md)；此处只写**使用时需要知道的**。

### 4.1 单行字数怎么数

| 计入 1 字 | 不计入 |
|-----------|--------|
| 中文汉字、英文字母、数字 | 标点（按规则去掉）、空格 |

中英文**不**按「显示宽度两套算法」区分计数；空格保留规则见下。

### 4.2 去标点（默认）

默认会去掉常见中英文标点、引号、括号、省略号等，但不会把所有标点都直接变成换行：

- 句号、问号、感叹号和原始换行会结束当前自然句；
- 逗号、分号、冒号、顿号、破折号和省略号只在自然句超长时作为候选断点；
- 引号、括号只删除，不会把引号内短词孤立成行。

**默认保留、不换行**：`%`、`％`（如 `增长50%`）。

可在设置中自定义「去除」与「保留」列表（例如保留 `+`、`-`）。未被内置分类识别的自定义去除符号默认只删除、不产生断点。设置 Drawer 提供「去除标点」开关与保留标点输入框；改完会写入本机配置，下次启动仍有效。

### 4.3 空格

| 场景 | 结果示例 |
|------|----------|
| 英文词之间 | 保留：`Hello world` |
| 英文与中文之间 | 保留：`使用 iPhone 拍摄`、`AI 技术` |
| 数字与英文之间 | 保留：`iPhone 15` |
| 数字与中文之间 | 去掉：`2024年` |
| 数字与 `%`/`％` | 无空格：`增长50%` |

### 4.4 断句如何工作（概念）

顺序固定：

1. 标点分级并去除 → 空格规范化 → 按句末符号形成自然句
2. 超长自然句 → 在原始逗号等候选、英文词界和词表断点间做**全局规则断句**
3. 可安全合并的短行会自动回并；找不到自然切法时先保留局部超长，供 LLM 或最终标记
4. 仍超长 → 进入 **LLM 发送池**（仅当已配置；按语义 / 口播习惯切，只改分行不改用词）
5. LLM 结果会检查内容守恒与有效切分；不合格会自动再试，最多 3 次
6. 仍超长或仍失败 → **标记**（LLM 不保证每行都 ≤ 最大字数；标记行复制前请留意）

因此：**不配 LLM 也能完成大部分工作**；LLM 是「最后一小段超长行」的增强。

### 4.5 编辑断句词表（可选进阶）

规则断句只在**允许的位置**切行（不会在英文单词中间硬切）。若你常写某类口播稿，可微调词表以提高一次通过率。

| 操作 | 说明 |
|------|------|
| 打开 | FAB 上 **编辑规则**（在「处理文稿」左侧） |
| 编辑 | 左侧选类别（受保护词 / 后可断·词 / 后可断·字 / 前可断）；右侧 **一行一词** |
| 保存 | 右下角 **保存** → 写入本机 `settings.db`，下次处理生效 |
| 恢复默认 | 左下角 **恢复默认** 读出厂词表；须再点 **保存** 才写入库 |
| 取消 | 有未保存修改时会提示确认 |

四类含义（与内置词表文件对应）：

| 类别 | 含义 |
|------|------|
| 受保护词 | 禁止从中切断（每项最长 4 字），如固定短语 |
| 后可断·词 | 整词结束后可换行 |
| 后可断·字 | 单字结束后可换行 |
| 前可断 | 整词开始前可换行 |

出厂词表包含 `可能`、`需要`、`可以`、`仍然`、`能够`、`不能`、`真正`、`通常`、`容易`、`提供` 等通用高频谓语起点；`不可能`、`未必能够` 等固定组合会整体保留。高风险单字 `的`、`地`、`得`、`着`、`有`、`也`、`还`、`就`、`又`、`到` 已从新版出厂断点移除。已有本机词表不会被升级强制覆盖，但全局选点会降低这些高风险位置的优先级；如需采用新版出厂词表，请点击 **恢复默认** 后再 **保存**。

去标点、字数预设仍在 **设置**（`Ctrl+,`）中调整；与词表分开。

### 4.6 LLM（可选）

| 项 | 说明 |
|----|------|
| 何时有用 | 规则断句后仍有超长行，希望按语义再切 |
| 需要什么 | 设置里的 API 端点、模型名；环境变量 `SENTREALM_LLM_API_KEY` |
| 隐私 | **不会上传全文**；只发送仍超长的那几行（每批最多 10 行；详见架构 ADR-005） |
| 未配置时 | 自动跳过，超长行进入标记 |
| 处理前预检 | 已启用 LLM 时，「处理文稿」前会检测端点/模型/密钥是否可用；失败弹窗，不开始处理 |
| 自动返工 | 内容与原文对不上、或未真正拆开时会重试，满 3 次仍失败则标记 |
| 字数说明 | LLM 按语义切分，**不保证**每行都 ≤ 设置的最大字数；最终仍超长的行会标记 |

密钥与账号由你自行向模型服务商申请；SentRealm 不附带公用密钥。

## 5. 数据存在哪里（本机）

均为**本机文件**，无云端账号同步。

| 数据 | 典型位置（Windows） | 说明 |
|------|---------------------|------|
| 用户配置 | `%APPDATA%\SentRealm\settings.db` | 预设、去标点规则、**断句词表**、LLM 端点/模型等 |
| 文稿与项目（GUI 默认工作区） | `%USERPROFILE%\Documents\SentRealm\` | 项目/文稿文件夹；正文多为 `source.txt`，最近结果可为 `result.json` |
| API 密钥 | 环境变量 `SENTREALM_LLM_API_KEY` | **不**写入上述数据库 |

备份：复制 `Documents\SentRealm`（文稿）与必要时的 `settings.db`（偏好）。删除项目/文稿一般为**直接删除文件**，无回收站语义时请先自行备份。

cli / mcp 与桌面端**共用同一配置库**；文稿工作区仅桌面端（gui）读写，cli/mcp 不接入。

## 6. 其他入口（可选）

不需要 GUI 时，开发者或脚本可用：

| 入口 | 用途 | 文档 |
|------|------|------|
| **CLI** | `sentrealm preprocess -i in.txt -o out.txt` | [cli-mcp.md](../cli-mcp.md) |
| **MCP** | Agent 调用 `preprocess_text` | 同上 |

命令行参数里的 `--preset` / `--max-chars` 只影响**当次**处理，默认不改你在 GUI 里保存的设置。

## 7. 常见问题

### 处理后还有标点？

- 检查是否把该符号放进了「保留」列表。  
- 默认表未覆盖的生僻符号可手动加入「去除」列表。  
- 确认复制的是**处理后**文本，而不是左侧原文。

### 很多行被高亮（标记）？

- 字数上限是否过严（竖屏 10 对长句更严）。  
- 未配置 LLM 时，规则切不动的行会全部标记——可临时开启 LLM，或手动改稿。  
- 专有名词/英文过长时，可略提高自定义字数，或在原文中先断句。

### 复制到剪映后对不齐 / 要大改？

- 先确认**口播与文稿一致**（口误、临场发挥会导致匹配差）。  
- 检查是否误粘贴了带空行或未处理的原稿。  
- 允许少量微调；若大量长度问题，换预设或自定义字数再处理一次。

### 提示后端未就绪 / 无法处理？

- 等数秒再试（后端启动有健康检查超时窗口）。  
- 确认本机 **17300** 端口未被其他程序占用。  
- 安装包阶段：重启应用；开发构建：见 [本地运行 FAQ](../dev/running-locally.md)。

### 关闭软件后文稿还在吗？

- **配置**（预设、词表、LLM 端点等）写在 `%APPDATA%\SentRealm\settings.db`，会保留。  
- **文稿正文**：GUI **默认**保存在 `%USERPROFILE%\Documents\SentRealm\`（项目/文稿文件夹），关闭应用后仍在。  
- 重要定稿请同时保留你自己的原稿备份。

### 能一次处理很多文件吗？

当前产品定位为**单篇**处理。批量可用 CLI 自行写脚本循环调用；GUI 批量不在 MVP 范围。

### macOS / 手机能用吗？

主平台为 Windows 桌面。其他平台未作为当前交付目标。

## 8. 快速检查清单（发给剪辑前）

- [ ] 使用的是定稿、与成片口播一致的版本

- [ ] 复制的是处理后文本（无空行、一行一句）
