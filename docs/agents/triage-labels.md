# Triage Labels

这些 skills 基于 5 个标准分诊角色展开协作。本文档将这些角色映射至本仓库 Issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的角色 | 本仓库 tracker 中的 label | 含义 |
| -------------------------- | ------------------------- | ---- |
| `needs-triage`             | `needs-triage`            | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`              | 等待提交者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`         | 规格完备，可由离线 Agent 执行 |
| `ready-for-human`          | `ready-for-human`         | 需要人工介入实现 |
| `wontfix`                  | `wontfix`            | 不予处理 |

当某个 skill 提及对应角色时（例如“应用 ready-for-agent 分诊标签”），请使用本表中对应的 label 字符串。

后续可直接编辑“本仓库 tracker 中的 label”列，以适配实际使用的词汇。
